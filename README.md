# مترجم زنده بازی | GameTranslator

اپلیکیشن اندروید برای گرفتن تصویر صفحه با اجازهٔ کاربر، تشخیص متن بازی با Google ML Kit OCR و ترجمهٔ آن به فارسی.

## ساخت APK
هر بار که روی شاخهٔ `main` تغییری push شود، GitHub Actions نسخهٔ Debug را می‌سازد. همچنین می‌توان از زبانهٔ Actions اجرای دستی را انجام داد. فایل `GameTranslator-debug` در بخش Artifacts همان اجرای workflow قرار می‌گیرد.

## نصب و استفاده
1. APK را نصب کن.
2. برنامه را باز کن و «فعال‌سازی دکمه ترجمه» را بزن.
3. مجوز «نمایش روی برنامه‌های دیگر» را فعال کن.
4. در پنجرهٔ سیستم، اجازهٔ ضبط صفحه را بده.
5. بازی را باز کن و دکمهٔ شناور FA را بزن.
6. متن تشخیص‌داده‌شده پس از ترجمه در پنل پایین صفحه نشان داده می‌شود. برای بستن پنل روی آن بزن.

## نکات
- برای دریافت مدل ترجمهٔ هر زبان، بار اول اینترنت لازم است؛ ترجمه پس از دانلود مدل روی دستگاه انجام می‌شود.
- هر بار شروع ضبط صفحه نیازمند تأیید کاربر است.
- بعضی بازی‌ها به‌دلیل DRM یا سیاست امنیتی خود اجازهٔ ضبط تصویر نمی‌دهند.
- نسخهٔ فعلی نتیجهٔ ترجمه را در پنل پایین نشان می‌دهد؛ هنوز متن را دقیقاً روی جای اصلی در بازی جایگزین نمی‌کند.
- تست نهایی روی دستگاه واقعی باید جداگانه انجام شود.
